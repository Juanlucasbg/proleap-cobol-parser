# SaleADS Mi Negocio Full Workflow E2E

This folder contains an end-to-end Playwright test for the workflow named:

- `saleads_mi_negocio_full_test`

The test automates:

1. Google login entry flow
2. Sidebar `Negocio` -> `Mi Negocio` navigation
3. `Agregar Negocio` modal validation
4. `Administrar Negocios` page validation
5. `Informacion General` validation
6. `Detalles de la Cuenta` validation
7. `Tus Negocios` validation
8. `Terminos y Condiciones` validation (new tab or same tab)
9. `Politica de Privacidad` validation (new tab or same tab)
10. Final PASS/FAIL JSON report generation

## Why this is environment-agnostic

- No hardcoded SaleADS domain is used.
- URL is supplied at runtime via environment variable.
- UI actions prioritize visible text selectors.
- Legal-link checks support same-tab navigation and popup/new-tab behavior.

## Setup

From repository root:

```bash
cd e2e
npm install
npx playwright install
```

## Run

### Headless (default)

```bash
cd e2e
SALEADS_LOGIN_URL="https://<current-env-login-page>" npm run test:saleads-mi-negocio
```

### Headed

```bash
cd e2e
HEADED=true SALEADS_LOGIN_URL="https://<current-env-login-page>" npm run test:saleads-mi-negocio:headed
```

## Environment variables

- `SALEADS_LOGIN_URL` (recommended): full login page URL for current environment
- `SALEADS_BASE_URL` (fallback): alternative URL variable accepted by the test
- `SALEADS_URL` (fallback): alternative URL variable accepted by the test
- `SALEADS_ARTIFACTS_DIR` (optional): directory for screenshots + report (default: `artifacts`)
- `HEADED=true` (optional): run browser in headed mode

## Artifacts

Generated by default under `e2e/artifacts/`:

- `step_1_dashboard_loaded.png`
- `step_2_mi_negocio_expanded.png`
- `step_3_agregar_negocio_modal.png`
- `step_4_administrar_negocios_view.png`
- `step_8_terminos_y_condiciones.png`
- `step_9_politica_de_privacidad.png`
- `saleads_mi_negocio_full_test_report.json`

The JSON report includes:

- PASS/FAIL per requested report field
- Screenshot paths
- Final URLs for legal links
- Failure details by step (if any)
